# Production VST3 behavior — Phase 8

Phase 8 was authorized on 2026-11-17 for a locked-screen implementation. Actual Studio One, keyboard, VoiceOver and visible appearance acceptance remain pending.

VHS.vst3 is a native Apple Silicon Fx|Analyzer insert with matching mono or stereo input/output, 32/64-bit sample support, byte-preserving pass-through and a 16-channel MIDI event bus. It has a new production class ID, a distinct `VHSHostUI` Swift dylib/module and a production-only Objective-C bundle marker; the Phase 3A installed probe is not replaced. No capture devices or sharing permissions are opened. Audio bounce/offline processing preserves audio and does not export visuals. Bypass preserves pass-through and releases live input contributions.

The editor uses Signal and the shared node editor, mappings and preset browser. It owns no standalone menu/quit commands. Host Controls opens the fixed automation-slot list and sync selection. Each of 256 slots has a stable VST3 parameter ID (0x2000–0x20ff), an explicit graph-node UUID/key binding and a normalized value. Bindings are song-owned; reordering or loading a preset never reassigns a slot automatically. Missing/wired/non-numeric targets stay visibly unavailable until explicitly rebound. Expose to Host assigns the lowest never-bound slot, or returns the existing slot for that target. Clearing retires the slot without making it eligible for automatic reuse; an explicit rebind can reuse a lane. Assigning initializes from the target base value. Slot numeric gestures use host begin/value/end callbacks. Bound slots take precedence over legacy RGB lanes when both address the same target. Host playback overrides base values before MIDI/audio offsets without adding local undo entries. Graph edits retain scene undo; DAW automation has host ownership.

Free Run preserves seconds-based motion. Follow DAW is explicitly beat based: one quarter note equals one animation second, so frequency controls mean cycles per beat in this mode. Valid musical position is preferred; a valid tempo/sample-position pair is the fallback. Stops hold the supplied beat position; seeks and loops follow the next supplied position. Missing/stale timing holds the last valid beat and reports unavailable status. Timing is display-rate, not sample-accurate video. Offline contexts do not chase/render every audio block.

The versioned host envelope embeds the project graph/base values/seed/mappings/preset content/sync and slot bindings. The binary state also captures all 256 slot values independently of the editor, including automation with no editor open. Legacy RGB/project envelopes migrate; unsupported/truncated/invalid state leaves the prior instance unchanged. No library/project/device/display path or window visibility is required for recall. Project import/export is explicit and retains current instance ownership; import cannot overwrite an external file. State parsing/encoding and preset I/O never run from process().

Audio callbacks copy analysis samples to the existing bounded queue; the shared analyzer runs on a worker actor. RMS, peak, bands and transient use the same definitions as standalone. Overflow, format/transport discontinuity, suspension, offline/bypass and stale input clear live analysis/held notes. Control/transport snapshots use bounded atomic handoffs; no UI, disk, locks, heap allocation or GPU waits occur in process().

Studio One routing must be reaccepted with this production class ID. The feasibility routing was a stereo audio insert plus an instrument track targeting the Visual MIDI bus, with monitoring enabled for live notes/controllers. CCs use IMidiMapping controller parameters rather than raw CC event assumptions. Controller chase/stopped processing depends on the host; no data is shown as available when callbacks cease. Production live automation, song reopen, two-instance/editor/output lifetime and host-quit acceptance are pending.

## State and parameter contract

The production class ID is `B5A87F120EC54856A624B9EE6C820001`; bundle ID is `com.kike.vhs.vst3`, version 0.8.0. Legacy RGB IDs 0–2 retain their meanings. ID 3 is reserved hidden CC1 status, not a new visual lane. The controller discovery bank remains 0x1000…0x17ff; slots occupy 0x2000…0x20ff, and bypass is 0x3000. There are 2309 declared parameters. No slot index depends on effect/node ordering.

Binary stream magic `0x56485333` writes three legacy RGB doubles, 256 normalized slot doubles, normalized bypass, document byte count, and the bounded document bytes. The document is JSON `{format:"vhs-host", version:1, project:<base64 schema-5 project JSON>, bindings:[{slot,target:{node,key},enabled}]}`. The JSON document is limited to 128 KiB; all values/counts/version/types are validated before restore. Magic `0x56485331` (RGB) and `0x56485332` (RGB + project JSON) remain readable migration inputs. Restore publishes document/base controls together before advancing its revision. Continuous host slot values live in the atomic bank and binary stream, independently of editor document encoding. No live audio/MIDI/transport value is added to this state.
